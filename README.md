# De Witwasser

Landingspagina voor De Witwasser, een ophaal- en bezorgdienst voor de was van studenten in Groningen. Studenten zetten hun was klaar, wij halen op per pand of straat, laten wassen bij een bestaande wasserette en brengen het schoon terug op een vast moment.

Studentenconcept voor het vak Bedrijfskunde, Hanzehogeschool Groningen.

## Bekijken

Open `index.html` in een browser. Er is geen build-stap en geen backend nodig.

## Bestanden

- `index.html`: de pagina (hero, probleem, hoe het werkt, eerlijke vergelijking, aanmeldformulier, footer)
- `styles.css`: opmaak, mobile-first
- `script.js`: formuliervalidatie en animaties
- `logo.jpg`: logo

## Aanmeldingen

Het formulier heeft geen backend. Een aanmelding wordt alleen gelogd in de browserconsole.
